# Molecular models of fatty-acid monolayer surface-potential isotherms

Research repository for molecular-level explanations of Langmuir-film surface-potential isotherms, starting with stearic acid.

The project develops a falsifiable statistical-mechanical model linking chain packing, hydration-water orientation, surface dipoles, and charge-regulated Gouy-Chapman electrostatics. The research article, executable scripts, and tests are being assembled on a review branch.

**Status:** theoretical work in progress; no new experimental fit or validation is claimed.
